# Чернетка зміни GTM для /kneeq/

У контейнері GTM-TPZT7VDW створіть тригер Custom Event для `kneeq_clarity_ready` із умовою Page Path дорівнює `/kneeq/`. Встановіть його для поточного тега Clarity. Додайте виняток для звичайного запуску цього самого тега за шляхом `/kneeq/` і типом події, який відповідає чинному тригеру. Збережіть наявні тригери для інших сторінок. У Preview перевірте, що Clarity запускається один раз після `load`, і що маршрути інших сторінок зберігають попередній запуск.

На /kneeq/ у мобільному Preview перевірте PageView до `kneeq_clarity_ready`, а також InitiateCheckout з тестовою відповіддю сервера. Для браузерного Purchase використовуйте тестову конфігурацію контейнера й тестовий набір даних Meta. Перевірте однаковий `event_id` у браузерній та серверній подіях. Цей файл і подія в HTML не змінюють чинний контейнер.
