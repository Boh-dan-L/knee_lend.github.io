# Локальний патч платіжного сервісу bayer

Патч `bayer-00084-g2g.patch` розрахований на `main.py` з архіву вихідного коду ревізії Cloud Run `bayer-00084-g2g`. З архівом працюйте окремо від репозиторію сайту. Для перевірки виконайте `git apply --check /absolute/path/to/bayer-00084-g2g.patch` у каталозі розпакованого архіву.

Публікацію має випереджати оновлення Cloud Run. Ідемпотентність повторного запиту браузера залежить від серверного патча. Патч охоплює обидва тарифи `/kneeq/`.

Після підтвердженої оплати Cloud Run повертає WayForPay 503, якщо спроба доставки Purchase до Meta завершилася помилкою. WayForPay повторює вебхук протягом свого [вікна повторів](https://wiki.wayforpay.com/en/view/852102). Статус оплати при цьому залишається `paid`. Повтори використовують збережені час оплати й ідентифікатор події. Збої в доставці можна знайти за полем `meta_purchase_last_attempt` і відсутністю `meta_purchase_sent: true`.

Оновлення статусу оплати й резервування спроби Meta виконуються транзакціями Firestore. Якщо паралельний вебхук уже почав відправлення, наступний чекає повтору від WayForPay. Резервування діє до п’яти хвилин, тому повтор може продовжити доставку після зупинки інстансу. Відправлення в Meta відбувається поза транзакцією та використовує той самий `event_id`, якщо результат попередньої спроби невідомий.
