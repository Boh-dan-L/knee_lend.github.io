# Версія V13

Завантажте вміст папки на чинний хостинг, замінивши файли попередньої версії.

- На першому екрані: помітна кнопка «Пройти тест — 5 запитань» і пояснення, що тест допомагає зрозуміти відповідність курсу запиту.
- Для кого: сходи; біль і набряк після навантаження; скутість і артроз; попередня травма чи операція.
- Результати: 6 можливих змін завдяки курсу.
- Причини: 3 закриті акордеони з короткими тезами та повними поясненнями всередині.
- Повернуто 6 карток переваг із зображеннями та повну структуру етапів із критеріями переходу.
- Відгуки після автора відкриті.
- Модальне вікно: виправлено порядок завантаження скрипту; додано оновлення кешу CSS і JS через v=13.
- FAQ, платіжні product_id та логіка оплати збережені.

Перевірки: синтаксис JS, ресурси, посилання, унікальні ID, незмінність FAQ; DOM-перевірка відкриття/закриття/повторного відкриття модального вікна та повернення фокуса, двох гілок квізу й FAQ. Візуальна перевірка в реальному браузері та реальна оплата не виконувалися.
