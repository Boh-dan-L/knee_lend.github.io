# Kneeq — версія 14 (оновлення копірайту та персоналізований квіз)

## Що змінилося

1. **Перший екран:** заголовок тепер починається з реальних ситуацій (ходьба, присідання, сходи), підзаголовок описує користь готового плану. Збережено основну кнопку покупки та помітну кнопку квізу.
2. **Копірайт:** прибрано повтори «70+ відеовправ» із кількох блоків, переписано перехід після трьох причин повернення болю. П'ять карток комплектації тепер мають різні ціннісні акценти, PDF не змішано з Telegram. Видалено порожню картку.
3. **Структура та Telegram:** текст про етапи пояснює логіку переходу; блок Telegram — дії користувача після покупки.
4. **FAQ:** замість дублювання відповіді «Що відбудеться після оплати?» додано різницю форматів 590/1090 грн.
5. **Квіз — 5 кроків:**
   - можна обрати до трьох симптомів та до чотирьох установлених діагнозів;
   - вибір «складно сказати / немає діагнозу» взаємовиключний;
   - збережено запитання про попередні спроби, обмеження навантаження та бажаний формат;
   - результат має окремі блоки: відповіді, рекомендації щодо занять, логіка прогресії, тематичні бонуси та формат;
   - один результат може рекомендувати **кілька бонусних відео**, наприклад «Артроз» та «Біль навколо колінної чашечки»;
   - підстави показу бонусів відрізняються: за вказаним діагнозом або за описом симптомів (це не встановлення діагнозу);
   - попередження про діагностику розташоване внизу результату дрібнішим шрифтом;
   - при свіжій травмі, відсутності дозволу на навантаження, насторожливих симптомах або сумнівах в безпеці — замість прямого продажу показано пораду спершу уточнити допустиме навантаження;
   - відповіді **не зберігаються і не надсилаються** у трекінг, оплати чи на сервер (лише тимчасово у JS-пам'яті сторінки);
   - додано стилізацію, адаптацію під телефон, можливість змінити відповіді та перезапустити тест; плаваюча CTA не перекриває активний квіз.
6. **Відео Telegram:** замінено `video/telegram-demo.MOV` (HEVC) на `video/telegram-demo.mp4` (H.264, `faststart`); приблизний розмір 6,8 МБ → 2,1 МБ.
7. **Кеш:** версії CSS та JS підвищено до `v=14`.

## Що залишилось без змін

- JS та ID кнопок оплати (`knee_590` та `knee_1090`) і GTM;
- ціни, умови гарантії, основні блоки, скриншоти відгуків;
- структура файлів, сторінки `offer`, `privacy`, `thank-you-590`, `thank-you-1090`, `payment-failed`.

## Перевірки

- `node --check knee.js` — синтаксис без помилок.
- DOM-перевірки в Chromium при ширині 1440 та 390 px: 2 пов'язані бонуси для «біль навколо чашечки + артроз», коректна ціна формату, перезапуск квізу, відсутність горизонтального переповнення.
- Додаткові сценарії: кілька діагнозів, персональний формат, ліміт вибору, повернення назад зі збереженням відповіді, взаємовиключні опції, відсутній діагноз, обмеження після операції, насторожливі симптоми, вікно персонального розбору.
- Реальні платежі, дані аналітики та відображення на живому домені **не тестувалися**. Для DOM-перевірок зовнішні ресурси й платіжні скрипти відключалися, щоб тестувати локально без мережевих викликів.

## Перед публікацією перевірити

- Чи справді доступ **необмежений у часі** (ця умова вже була в початковому архіві і не змінювалася).
- Чи актуальні перекреслені ціни **1899/2899 грн** та факт **3000+ учасників** (ці твердження збережені з вихідного сайту).
- Чи підтверджуються всі **6 бонусних тем** фактичним вмістом курсу.
- Після завантаження на сайт: виконати тестову покупку обох форматів і перевірити платежі, редиректи, аналітику й запуск відео у різних браузерах.

## Розгортання

Завантажте **вміст папки `kneeq/`** у директорію вашого сайту (як у попередній версії). Важливо оновити разом `index.html`, `knee.css`, `knee.js` та `video/telegram-demo.mp4` і видалити старий `telegram-demo.MOV`, якщо він більше не використовується.
