# Knee6 — оновлена версія

## Основні зміни
- посилений блок «Чому біль повертається»;
- посилений блок «Чому саме ця програма, а не YouTube / Instagram»;
- Telegram-демо об’єднано з блоком прогресії;
- відгуки розділено на ранній блок соціального доказу та більший блок нижче;
- повернуто формат «Курс + індивідуальні рекомендації» за 890 грн;
- повернуто відгуки про індивідуальний розбір;
- фінальний pricing містить 390 і 890 грн;
- усі основні CTA-кнопки приведено до одного кольору;
- палітра сайту уніфікована навколо кольорів Hero.

## Де змінювати кольори
На самому початку `knee.css` є блок `:root` з коментарем:
`ЄДИНА ПАЛІТРА САЙТУ — змінюйте кольори тут`.

Основні змінні:
- `--theme-deep`
- `--theme-deep-2`
- `--theme-mid`
- `--theme-page`
- `--theme-soft-blue`
- `--theme-accent`
- `--theme-cta`
- `--theme-cta-hover`
- `--theme-text`
- `--theme-muted`
- `--theme-border`
